Rankings and category comparison with readable labels. Default choice over a column chart when labels are names. Stacks label above the bar under 380px card width.

```jsx
<HBarChart showRank format="number" target={30} data={[
  { label: 'Marina Alves', sub: 'Design', value: 38, prefix: <Avatar name="Marina Alves" size="sm" /> },
  { label: 'João Kim', sub: 'Conteúdo', value: 31 }]} />
```
