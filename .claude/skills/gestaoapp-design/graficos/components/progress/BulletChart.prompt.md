Replace gauges when you have several "real vs meta" rows. Ink tick = target; thin bar = actual.

```jsx
<BulletChart format="hours" overIsBad rows={[
  { label: 'Redesign do site', value: 182, target: 200, ranges: [120, 180, 240] },
  { label: 'Vídeo da marca', value: 112, target: 96, ranges: [60, 90, 120] }]} />
```
