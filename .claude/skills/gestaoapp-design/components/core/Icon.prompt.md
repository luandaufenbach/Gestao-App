Renders a Lucide outline icon by name — the only icon set in gestaoApp; never use emoji or hand-drawn SVGs.

```jsx
<Icon name="layout-grid" />
<Icon name="calendar" size={14} color="var(--text-tertiary)" />
<Icon name="check" size={16} strokeWidth={2.25} />
```

- Sizes: 13–14 inside meta rows, 16–17 in nav/buttons, 20 in tab bar.
- `ICON_NAMES` lists every bundled glyph (same set as assets/icons/).
