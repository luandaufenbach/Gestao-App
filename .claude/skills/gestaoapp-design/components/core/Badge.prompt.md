Pill label for counts ("4"), project health ("No prazo", "Em risco") and meta tags.

```jsx
<Badge size="sm">4</Badge>
<Badge tone="success">No prazo</Badge>
<Badge tone="warning">Em risco</Badge>
<Badge tone="brand" dot>Em andamento</Badge>
<Badge tone="accent">5 / 5 concluídas</Badge>
```

- `brand-solid` for the active nav count; `inverse` for "+4" style overflow.
- For task workflow states prefer `StatusBadge`.
